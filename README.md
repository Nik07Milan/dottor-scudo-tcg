# DottorScudo TCG

Gioco di carte multiplayer ispirato al fumetto **Dottor Scudo** — *il paladino degli impiegati contro la burocrazia aziendale*.

## Avvio rapido
```bash
npm install
npm test
```

## Prima di iniziare
1. ~~Copia `dottorscudo-albi.json` in `data/`.~~ Fatto.
2. Scompatta gli zip delle immagini in `assets/` (vedi `assets/README.md`).
3. Apri il progetto in Claude Code: le istruzioni sono in `CLAUDE.md`, il design in `docs/GDD.md`.

Le immagini e i personaggi appartengono all'autore del fumetto: tieni il repo privato.
